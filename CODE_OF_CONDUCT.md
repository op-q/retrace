# Code of conduct

RETRACE contributors are expected to make technical collaboration safe,
respectful, and useful.

Be constructive, assume good faith while still examining evidence, welcome
questions from learners, credit others' work, respect privacy, and critique code
or decisions rather than people. Harassment, discrimination, threats, unwanted
sexual attention, deliberate intimidation, doxxing, and publishing another
person's private information are unacceptable.

Maintainers may edit or remove contributions and restrict participation when
behavior harms the community. Enforcement concerns should be reported privately
through the channel described in [SECURITY.md](SECURITY.md), not debated in a
public issue when doing so would expose a reporter or affected person.

Maintainers should assess context, respond proportionally, protect reporter
privacy, avoid conflicts of interest, and document moderation decisions.
